# AdVerity

AI drafts. Copy experts refine. Clients approve.

The review-ready ad pack is behind `FEATURE_REVIEW_READY_AD_PACK`, which is off until the server environment sets it to `true`.

How to run a pilot, review a pack, and turn the feature off: [docs/features/review-ready-ad-pack/user-guide.md](docs/features/review-ready-ad-pack/user-guide.md).

Operator procedures: [docs/ops/review-ready-ad-pack-devsecops-playbook.md](docs/ops/review-ready-ad-pack-devsecops-playbook.md).

The runtime host is Render (`render.yaml`). The strategy and revised master prompt: [docs/brief/AdVerity-Strategy-and-Revised-Master-Prompt.md](docs/brief/AdVerity-Strategy-and-Revised-Master-Prompt.md).
